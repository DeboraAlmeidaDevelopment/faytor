Execução Local & Restrição de CORS Detectada

Para manter o código 100% modular, limpo e organizado em arquivos separados (`/views`), a aplicação utiliza requisições assíncronas de rede (`fetch`) para carregar dinamicamente as telas das ferramentas.

Por motivos de segurança, os navegadores modernos bloqueiam essa requisição quando o arquivo é aberto diretamente com cliques no arquivo local (`file://`).

Como resolver rapidamente para testar:

Opção 1: Servidor Python (Recomendado)

Abra o terminal na pasta deste projeto e execute:

python -m http.server 8080

Depois acesse no navegador: http://localhost:8080

Opção 2: VS Code Live Server

Se você utiliza o VS Code:

  • Instale a extensão Live Server.
  • Clique com o botão direito em index.html.
  • Selecione "Open with Live Server".
