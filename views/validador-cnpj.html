# Documento Resultado Motivo

O que o validador confere

O validador aceita CNPJs numéricos e alfanuméricos, com ou sem pontuação, e converte letras minúsculas para maiúsculas. Em seguida, aplica estas verificações:

  • Tamanho: exatamente 14 posições depois de remover a pontuação.
  • Formato: as 12 primeiras posições aceitam letras ou números; as 2 últimas precisam ser numéricas.
  • Sequência repetida: valores como 00.000.000/0000-00 são recusados.
  • Dígitos verificadores: calculados com módulo 11, convertendo cada caractere para o código ASCII menos 48.

Quando o tamanho e o formato estão corretos, o quadro Como chegamos a este resultado mostra a raiz, a ordem do estabelecimento e as duas somas ponderadas, com o valor numérico de cada letra entre parênteses.

Exemplo de erro: 12.ABC.345/01DE-36

O primeiro dígito confere: a soma é 459, o resto é 8 e o esperado é 3. No segundo, a soma é 424, o resto é 6 e o esperado é 5, mas o informado é 6. O resultado é "Segundo dígito verificador inválido".

No formato alfanumérico, um erro comum é trocar a letra O pelo número 0. As duas formas são aceitas nas 12 primeiras posições, mas têm valores diferentes no cálculo (O = 31 e 0 = 0). Por isso a troca quase sempre invalida os dígitos verificadores. Vale a mesma atenção para a letra I e o número 1.

Como validar CNPJ em JavaScript (numérico e alfanumérico)

Como o código ASCII de "0" é 48, a mesma conversão serve para números e letras:

function validarCNPJ(valor) {
  const cnpj = String(valor).replace(/[^a-z0-9]/gi, '').toUpperCase();
  if (!/^[A-Z0-9]{12}\d{2}$/.test(cnpj) || /^(.)\1{13}$/.test(cnpj)) return false;
  const pesos = [6, 5, 4, 3, 2, 9, 8, 7, 6, 5, 4, 3, 2];
  const digito = (base, pesosUsados) => {
    const soma = [...base].reduce((total, c, i) => total + (c.charCodeAt(0) - 48) * pesosUsados[i], 0);
    const resto = soma % 11;
    return resto < 2 ? 0 : 11 - resto;
  };
  const d1 = digito(cnpj.slice(0, 12), pesos.slice(1));
  const d2 = digito(cnpj.slice(0, 13), pesos);
  return cnpj.endsWith(`${d1}${d2}`);
}

validarCNPJ('12.ABC.345/01DE-35'); // true
validarCNPJ('11.222.333/0001-81'); // true

Como validar CNPJ em Python

import re

PESOS = [6, 5, 4, 3, 2, 9, 8, 7, 6, 5, 4, 3, 2]

def validar_cnpj(valor: str) -> bool:
    cnpj = re.sub(r"[^A-Za-z0-9]", "", valor).upper()
    if not re.fullmatch(r"[A-Z0-9]{12}\d{2}", cnpj) or cnpj == cnpj[0] * 14:
        return False

    def digito(base: str, pesos: list[int]) -> int:
        soma = sum((ord(c) - 48) * p for c, p in zip(base, pesos))
        resto = soma % 11
        return 0 if resto < 2 else 11 - resto

    return cnpj[-2:] == f"{digito(cnpj[:12], PESOS[1:])}{digito(cnpj[:13], PESOS)}"

Se o seu sistema ainda usa uma rotina antiga, que converte o CNPJ para número ou remove tudo o que não é dígito, ela vai recusar ou corromper os CNPJs alfanuméricos. Revise essas rotinas antes de receber cadastros no novo formato.

O que um CNPJ válido não garante

O cálculo confirma apenas a coerência dos dígitos. Ele não consulta a Receita Federal e não indica se a empresa existe, se está ativa, qual é a razão social ou quem são os sócios. Essas informações dependem da consulta oficial ao cadastro.
