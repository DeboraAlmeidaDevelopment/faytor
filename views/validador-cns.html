# Documento Resultado Motivo

Como o validador confere o CNS

Depois de remover espaços e outros caracteres, o validador verifica:

  • Tamanho: exatamente 15 dígitos.
  • Primeiro dígito: 1 ou 2 para cartões definitivos; 7, 8 ou 9 para provisórios. Qualquer outro início é recusado.
  • Soma ponderada: cada dígito é multiplicado por um peso de 15 a 1, da esquerda para a direita, e a soma precisa ser múltipla de 11, ou seja, ter resto 0 na divisão por 11.

A mesma soma final vale para os dois tipos. Nos cartões definitivos, o dígito verificador é calculado justamente para que a soma dos 15 dígitos dê resto 0. Nos provisórios, o próprio número já é emitido com essa propriedade.

Exemplo: um dígito alterado

O cartão 170 2345 6789 0006 é válido: a soma ponderada é 451, e 451 = 11 × 41. Troque o último dígito por 7: a soma passa a ser 1×15 + 7×14 + 0×13 + 2×12 + 3×11 + 4×10 + 5×9 + 6×8 + 7×7 + 8×6 + 9×5 + 0×4 + 0×3 + 0×2 + 7×1 = 452, com resto 1, e o validador recusa o número. O quadro Como chegamos a este resultado mostra essa soma completa para qualquer número com 15 dígitos.

Como validar CNS em JavaScript

function validarCNS(valor) {
  const cns = String(valor).replace(/\D/g, '');
  if (!/^[12789]\d{14}$/.test(cns)) return false;
  const soma = [...cns].reduce((total, n, i) => total + Number(n) * (15 - i), 0);
  return soma % 11 === 0;
}

validarCNS('170 2345 6789 0006'); // true
validarCNS('170 2345 6789 0007'); // false

Como validar CNS em Python

import re

def validar_cns(valor: str) -> bool:
    cns = re.sub(r"\D", "", valor)
    if not re.fullmatch(r"[12789]\d{14}", cns):
        return False
    return sum(int(n) * (15 - i) for i, n in enumerate(cns)) % 11 == 0

Erros comuns com números de CNS

  • Número cortado ou arredondado: planilhas transformam 15 dígitos em notação científica (1,70235E+14) e perdem os últimos dígitos. Formate a coluna como texto antes de colar ou importar.
  • Confusão com CPF: alguns cadastros aceitam CPF ou CNS no mesmo campo. Um CPF tem 11 dígitos e é recusado aqui pelo tamanho.
  • Início fora da regra: números que começam com 0, 3, 4, 5 ou 6 não seguem nenhum dos dois formatos.

Para conferir uma lista inteira, use a seção Validar CNS em lote, que aceita até 1.000 números e exporta o resultado em CSV. Para criar números de teste, incluindo o caso do sufixo 001, use o Gerador de CNS.

O que a validação não comprova

Um resultado válido confirma apenas a estrutura matemática. A ferramenta não consulta a base do SUS e não comprova cadastro, identidade do paciente ou direito a atendimento.
