O que o validador confere, na ordem

O validador remove pontos, traços e espaços e aplica quatro verificações. A primeira que falhar define a mensagem exibida:

  • Quantidade de dígitos: precisam ser exatamente 11. Um CPF com 10 dígitos costuma indicar um zero à esquerda perdido ao ser salvo como número.
  • Sequência repetida: números como 111.111.111-11 até passam no cálculo, mas são recusados porque não correspondem a inscrições reais.
  • 1º dígito verificador: soma dos 9 primeiros dígitos com pesos de 10 a 2.
  • 2º dígito verificador: soma dos 10 primeiros dígitos com pesos de 11 a 2.

Quando a quantidade de dígitos está certa, o quadro Como chegamos a este resultado mostra as somas, os restos e o dígito esperado em cada etapa. Assim dá para ver exatamente qual posição diverge.

Exemplo de CPF inválido explicado

Digite 123.456.789-00. O primeiro verificador confere: a soma ponderada é 210, o resto é 1 e o dígito esperado é 0. No segundo, a soma 1×11 + 2×10 + 3×9 + 4×8 + 5×7 + 6×6 + 7×5 + 8×4 + 9×3 + 0×2 dá 255, o resto é 2 e o dígito esperado é 9, mas o informado é 0. O resultado é "Segundo dígito verificador inválido", e o número correto seria 123.456.789-09.

Esse tipo de divergência costuma vir de erro de digitação. Os pesos diferentes para cada posição fazem o cálculo detectar a grande maioria das trocas de um único algarismo e das inversões entre dígitos vizinhos.

Como validar CPF em JavaScript

A função abaixo aplica as mesmas regras desta página e pode ser usada no front-end ou em Node.js:

function validarCPF(valor) {
  const cpf = String(valor).replace(/\D/g, '');
  if (cpf.length !== 11 || /^(\d)\1{10}$/.test(cpf)) return false;
  const digito = (base, pesoInicial) => {
    const soma = [...base].reduce((total, n, i) => total + Number(n) * (pesoInicial - i), 0);
    const resto = soma % 11;
    return resto < 2 ? 0 : 11 - resto;
  };
  const d1 = digito(cpf.slice(0, 9), 10);
  const d2 = digito(cpf.slice(0, 10), 11);
  return cpf.endsWith(`${d1}${d2}`);
}

validarCPF('123.456.789-09'); // true
validarCPF('123.456.789-00'); // false

Como validar CPF em Python

import re

def validar_cpf(valor: str) -> bool:
    cpf = re.sub(r"\D", "", valor)
    if len(cpf) != 11 or cpf == cpf[0] * 11:
        return False

    def digito(base: str, peso_inicial: int) -> int:
        soma = sum(int(n) * (peso_inicial - i) for i, n in enumerate(base))
        resto = soma % 11
        return 0 if resto < 2 else 11 - resto

    return cpf[-2:] == f"{digito(cpf[:9], 10)}{digito(cpf[:10], 11)}"

Valide sempre no servidor, mesmo quando o formulário já valida no navegador: a validação no front-end melhora a experiência, mas pode ser contornada.

Validar uma lista de CPFs

Para conferir uma base inteira, cole os números na seção Validar CPF em lote, um por linha. A tabela indica o motivo de cada recusa, e o resultado pode ser copiado ou baixado em CSV, com separador ponto e vírgula, para abrir em planilhas. Para criar números válidos de teste, use o Gerador de CPF.

Válido não significa regular

A validação é matemática: confirma que os dígitos verificadores são coerentes com a base. Ela não consulta a Receita Federal e não informa se o CPF existe, se está regular ou a quem pertence. Para isso, é necessária a consulta oficial à situação cadastral.
