# Documento Resultado Motivo

O que o validador confere

Depois de remover pontos, traços e espaços, o validador verifica:

  • Tamanho: exatamente 11 dígitos.
  • Sequência repetida: números com todos os dígitos iguais são recusados.
  • Dígito verificador: soma dos 10 primeiros dígitos com os pesos 3, 2, 9, 8, 7, 6, 5, 4, 3 e 2. O dígito esperado é 11 menos o resto da divisão por 11, e os resultados 10 e 11 viram 0.

A regra vale para PIS, PASEP, NIT e NIS, que compartilham o mesmo formato.

Exemplo de número inválido

Digite 120.33928.73-4. A soma ponderada é 175, o resto é 10 e o dígito esperado é 11 − 10 = 1, mas o informado é 4. O validador responde "Dígito verificador do PIS inválido", e o quadro Como chegamos a este resultado mostra cada multiplicação.

Por que a validação do CPF não serve para o PIS

Os dois documentos têm 11 dígitos, mas a semelhança para aí. O CPF tem dois dígitos verificadores, e o PIS tem só um, calculado com outra sequência de pesos. Na maioria dos casos, um PIS válido não passa na validação de CPF, e vice-versa. Formulários que aceitam "CPF ou PIS" no mesmo campo precisam testar as duas regras e informar qual documento foi reconhecido.

Como validar PIS/PASEP em JavaScript

function validarPIS(valor) {
  const pis = String(valor).replace(/\D/g, '');
  if (pis.length !== 11 || /^(\d)\1{10}$/.test(pis)) return false;
  const pesos = [3, 2, 9, 8, 7, 6, 5, 4, 3, 2];
  const soma = pesos.reduce((total, peso, i) => total + Number(pis[i]) * peso, 0);
  const digito = 11 - (soma % 11);
  return Number(pis[10]) === (digito >= 10 ? 0 : digito);
}

validarPIS('120.33928.73-1'); // true

Como validar PIS/PASEP em Python

import re

PESOS = [3, 2, 9, 8, 7, 6, 5, 4, 3, 2]

def validar_pis(valor: str) -> bool:
    pis = re.sub(r"\D", "", valor)
    if len(pis) != 11 or pis == pis[0] * 11:
        return False
    digito = 11 - sum(int(n) * p for n, p in zip(pis, PESOS)) % 11
    return int(pis[10]) == (0 if digito >= 10 else digito)

O que a validação não verifica

O resultado confirma apenas o tamanho e o dígito verificador. Ele não consulta Caixa, Banco do Brasil ou INSS, e não informa se o número está cadastrado, a quem pertence ou se há benefício a receber.
