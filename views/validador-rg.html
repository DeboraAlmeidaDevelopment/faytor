# Documento Resultado Motivo

O que o validador confere

O validador remove pontos, traços e espaços, converte o x minúsculo em X e verifica:

  • Tamanho: 9 posições, sendo 8 dígitos de registro e o dígito verificador.
  • Posição do X: a letra só é aceita na última posição.
  • Dígito verificador (padrão SSP-SP): a soma dos 8 primeiros dígitos com os pesos 2 a 9 define o dígito esperado, que é 11 menos o resto da divisão por 11. O resultado 10 vira X, e 11 vira 0.

O quadro Como chegamos a este resultado mostra a soma completa e o dígito esperado para qualquer número com 9 posições.

Exemplo de RG inválido

Digite 24.678.131-9. A soma 2×2 + 4×3 + 6×4 + 7×5 + 8×6 + 1×7 + 3×8 + 1×9 é 163, o resto é 9 e o dígito esperado é 11 − 9 = 2, mas o informado é 9. O validador responde que o dígito está incorreto para o padrão de São Paulo. O número correto seria 24.678.131-2.

Note que o dígito esperado é 11 menos o resto, e não o próprio resto. Implementações que usam o resto diretamente aceitam números errados e recusam RGs corretos. Se a sua rotina diverge deste validador em vários números, vale conferir esse ponto.

RG de outros estados

Cada estado define a própria numeração, e muitos não publicam a regra do dígito verificador. Por isso, um RG emitido fora de São Paulo pode ser recusado aqui mesmo sendo legítimo, e isso não significa que o documento seja falso. Em sistemas com usuários de vários estados, aplique o cálculo apenas quando a UF emissora for SP. Para as demais, valide só o formato básico e guarde a UF junto do número.

Como validar RG de SP em JavaScript

function validarRGSP(valor) {
  const rg = String(valor).toUpperCase().replace(/[^0-9X]/g, '');
  if (!/^\d{8}[\dX]$/.test(rg)) return false;
  const soma = [...rg.slice(0, 8)].reduce((total, n, i) => total + Number(n) * (i + 2), 0);
  const resultado = 11 - (soma % 11);
  const esperado = resultado === 10 ? 'X' : resultado === 11 ? '0' : String(resultado);
  return rg[8] === esperado;
}

validarRGSP('24.678.131-2'); // true
validarRGSP('24.678.135-x'); // true

Como validar RG de SP em Python

import re

def validar_rg_sp(valor: str) -> bool:
    rg = re.sub(r"[^0-9X]", "", valor.upper())
    if not re.fullmatch(r"\d{8}[\dX]", rg):
        return False
    resultado = 11 - sum(int(n) * (i + 2) for i, n in enumerate(rg[:8])) % 11
    esperado = {10: "X", 11: "0"}.get(resultado, str(resultado))
    return rg[8] == esperado

O que a validação não comprova

O cálculo confirma apenas a coerência do dígito no padrão paulista. Ele não consulta a SSP, não comprova que o documento foi emitido e não identifica o titular.
